# 프로젝트 시작 프롬프트

이 프로젝트를 처음부터 만든다면 AI에게 한 번에 줄 수 있는 프롬프트입니다.
지금까지 만든 결과를 거꾸로 정리한 것이라, 실제로는 만들면서 바뀐 점이 많습니다 (README의 '시행착오와 배운 점' 참고).

```text
국민연금 공개 데이터로 한국 회사의 평균 연봉을 추정하고, DART 공시로 검증한 뒤,
AI 에이전트와 웹 서비스로 보여주는 프로젝트를 만들고 싶어.

[목표]
- 취준생·이직 준비 직장인·지방 구직자가 "이 회사 연봉은 얼마고, 그 숫자를 얼마나 믿어도 되는지" 알 수 있게 한다.

[데이터]
- 국민연금공단 가입 사업장 내역(공공데이터포털, 월별 파일): 가입자 수, 고지 금액, 입·퇴사자 수, 업종, 지역
- DART 사업보고서: 상장사 직원 1인 평균 급여, 평균 근속연수 (정답으로 사용)
- 고용노동부 고용형태별노동실태조사(KOSIS): 업종 × 근속 구간별 임금 (연차별 참고 연봉용)

[분석]
1. 국민연금 데이터 정제: 회사명 정리, 지점 합치기, 중복·이상치 점검
2. 보험료로 평균 월급을 거꾸로 계산해 1차 추정 연봉을 만든다
3. 상장사와 이름으로 매칭해 실제 공시 연봉과 비교하고, 보험료 상한 때문에 낮게 나오는 부분을 보정 모델로 고친다
4. 교차검증으로 오차를 재고, 비슷한 회사의 오차로 "가능성 높은 범위"와 정확도 신호등을 만든다
5. 소득 기준 시점(매년 7월에 전년도 소득으로 바뀜)을 확인하고 정답과 같은 해 자료를 쓴다
6. 12개월 퇴사율·직원 수 추이, 작은 회사(10명 미만은 묶음 평균), 연차별 참고 연봉을 추가한다

[AI 에이전트]
- 회사 검색, 연봉 조회, 회사 비교, 업종 순위, 비슷한 회사 추천, 방법·한계 설명을 도구로 만든다 (MCP 서버로도 제공)
- 브랜드명은 법인명으로 바꿔 찾는다 (토스 → 비바리퍼블리카)
- 금액은 도구가 준 문장을 그대로 쓰고, 답 속 금액은 도구 결과와 자동 대조한다
- 질문 28개로 자동 평가하고, 실패는 기준을 느슨하게 하지 않고 원인을 고친다

[웹 서비스 (Streamlit, 무료 배포)]
- 첫 화면에 검색창 하나: 회사 이름은 AI 없이 바로, 질문은 AI가 답한다
- 글자를 치는 동안 회사 목록이 업종·지역·직원 수와 함께 뜨고, 오타·영어 이름도 찾는다
- 결과는 맨 위 한 줄 결론 + 그 아래 자세한 내용 (범위, 카드, 연차별 참고 연봉, 연도별 변화, 채용공고 링크)
- 색은 뜻별로 세 가지: 추정 = 파랑, 실제 공시 = 연한 핑크, 참고값 = 회청색
- 추정과 실제 공시가 다르면 이유를 경우별로 보여준다
- 조건 필터(업종·지역·규모·연봉·직원을 늘린 회사), 공유 주소, 👍👎 피드백, 휴대폰 화면 지원
- 비밀값(API 키, 비밀번호)은 코드가 아니라 Secrets에만 넣는다

[원칙]
- 검증할 수 없는 값은 숨기지도 꾸미지도 않고 "참고용"이라고 밝힌다
- 한계는 화면에서 사용자가 바로 알 수 있게 표시한다
- 화면 숫자와 문장이 맞는지 여러 회사로 자동 점검한다

[결과물]
- 분석 코드와 검증 보고서, README(방법·결과·한계·실행 방법)
- AI 에이전트 + MCP 서버, 배포된 웹 서비스
- 문제 해결 과정과 한계·대처를 담은 포트폴리오
```
